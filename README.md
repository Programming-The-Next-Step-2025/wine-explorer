
# vinexplorer

<!-- badges: start -->
<!-- badges: end -->

**vinexplorer** is an R package that ships a Shiny app for exploring wines on an interactive map. Users can filter by wine color, click a specific region and then select an individual wine to see details (grape, vintage, appellation, style, and characteristics).

## Installation

You can install the development version of vinexplorer from [GitHub](https://github.com/) with:

``` r
devtools::install_github("Programming-The-Next-Step-2025/wine-explorer")
library(vinexplorer)
```

## In the app: 

- You can choose one or more types of wine you are interested in (e.g. only reds). All selected by default. 
- Click a region marker to see different wines from that specific region. 
- Pick a wine and view details, such as grape, vintage, price, appellation, style, characteristics.
