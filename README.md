
# vinexplorer

<!-- badges: start -->
<!-- badges: end -->

**vinexplorer** is an R package that ships a Shiny app for exploring wines on an interactive map. Users can filter by wine color, click a specific region and then select an individual wine to see details (grape, vintage, price, and notes).

## Installation

You can install the development version of vinexplorer from [GitHub](https://github.com/) with:

``` r
devtools::install_github("Programming-The-Next-Step-2025/wine-explorer")
```
